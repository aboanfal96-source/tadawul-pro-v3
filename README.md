# منصة تداول احترافية — السوق السعودي

منصة تحليل فني متكاملة للسوق المالي السعودي مع بيانات حقيقية من Yahoo Finance.

## المميزات

- **223+ سهم سعودي** من جميع قطاعات تداول
- **أسعار حقيقية** من Yahoo Finance (مؤخرة 15 دقيقة)
- **10 استراتيجيات تحليل فني**: كلاسيك، هارمونيك، إيليوت، متوسطات، مذبذبات، شموع، إيشيموكو، بولنجر، VWAP، متعدد
- **أدوات رسم تفاعلية**: خط، أفقي، فيبوناتشي، قناة، مستطيل، سهم، نص، قياس
- **فلتر الاستراتيجيات**: يُظهر أقوى الأسهم بناءً على الإشارات
- **دفتر الأوامر** وسجل الصفقات
- **مؤشرات**: RSI، MACD، Stochastic، Bollinger، VWAP، Ichimoku

## النشر على Vercel

1. ارفع المشروع على GitHub
2. اذهب إلى [vercel.com](https://vercel.com)
3. اختر "Import Git Repository"
4. اختر المستودع وانشر

## ملاحظة

بيانات Yahoo Finance مؤخرة 15 دقيقة. المنصة للأغراض التعليمية فقط وليست نصيحة استثمارية.
